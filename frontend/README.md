# Демо-интерфейс

Локальный интерфейс «ИИ-сторожа»: HTML, CSS и JavaScript без сборки и CDN.
Файлы обслуживает существующий FastAPI-сервер с того же адреса, что и API.
Визуальный эксперимент повторяет основные приёмы [официального сайта «Группы Астра»](https://astra.ru/):
белую шапку, голубые акценты, крупные заголовки и прямоугольные кнопки.
Логотип и шрифт сохранены локально, сетевые запросы за оформлением не нужны.

Из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r api/requirements.txt
.\.venv\Scripts\python.exe -m api
```

Откройте http://127.0.0.1:8000/. Для другого порта: `python -m api --port 8080`.
Если сервер уже был запущен до добавления интерфейса, остановите его через Ctrl+C и запустите заново.
Для правок HTML/CSS/JS достаточно обновить страницу; для изменений Python перезапустите сервер
или используйте `python -m api --reload`.

## Как пользоваться

1. Выберите демо-профиль Developer, SRE или Admin и введите запрос.
2. При необходимости раскройте историю диалога и текстовые вложения, добавьте записи.
3. «Проверить запрос» вызывает только `/v1/check`, показывает решение, риск, вероятность атаки и объяснение.
4. «Проверить и передать» отдельно проверяет запрос и передаёт разрешённый пакет локальному демо-агенту.
5. При решении `confirm` нажмите «Подтвердить передачу», проверьте сохранённый текст и роль,
   отметьте явное согласие и нажмите «Подтвердить и передать».
6. В «Журнале решений» доступны фильтры Allow / Confirm / Block, обновление и загрузка следующих страниц.
7. «Настройка политики» открывает страницу-заглушку; редактирование правил пока недоступно.

`it_ops_agent` — технический идентификатор целевого DevOps-агента из задания.

Для демонстрации предусмотрены примеры чтения логов, production-рестарта и инъекции.
Production-рестарт выбирает SRE; переключение той же команды на Developer демонстрирует запрет по роли.

Изменение текста, роли, истории или вложения сбрасывает результат и доступное подтверждение:
изменённый пакет нужно проверить заново. До согласия передачи нет; ошибочные запросы не отправляются.
Токены подтверждения, тексты и вложения остаются только в памяти страницы, не сохраняются в localStorage.
После перезагрузки страницы проверку нужно повторить. Демонстрационный агент фиксирует получение
квитанцией, без выполнения shell-команд.

Роли являются выбираемыми демо-профилями. При `GUARD_DEMO_ENABLED=0` кнопка передачи отключается,
при этом независимая проверка и журнал доступны. Все сообщения сервера и пользовательские тексты
выводятся как текст, без вставки HTML.

## Файлы

- `index.html` — интерфейс и шаблоны редакторов контекста.
- `assets/styles.css` — адаптивная раскладка для настольного и мобильного экрана.
- `assets/astra-theme.css` — оформление в стиле сайта «Группы Астра».
- `assets/app.js` — запросы к API, состояния результата, подтверждение и журнал.
- `assets/astra-logo.svg` — [оригинальный логотип с astra.ru](https://astra.ru/colorLogoAstra.svg).
- `assets/astra-mark.svg`, `assets/favicon.svg` — графический знак, выделенный из оригинального SVG без изменения геометрии.
- `assets/fonts/` — PT Astra Fact Regular/Bold, локальные WOFF2 из CSS официального сайта.

Контракт и настройка сервера описаны в [api/README.md](../api/README.md).
