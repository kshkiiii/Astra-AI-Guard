# Дополнительные данные для ИИ-сторожа

Здесь хранятся закреплённые источники, переводы, адаптация под формат «Астра»
и скрипт воспроизводимой подготовки. Дата подготовки: 21 ноября 2026.

## Источники и атрибуция

| Источник | Закреплённая версия | Как используется |
| --- | --- | --- |
| [dmtrdr/russian_prompt_injections](https://huggingface.co/datasets/dmtrdr/russian_prompt_injections) | `2bb249ed6b692f258ac9a369015aeafe1f011fc7` | 40 отобранных русских запросов из поднабора `openai_synthetic` |
| [neuralchemy/Prompt-injection-dataset](https://huggingface.co/datasets/neuralchemy/Prompt-injection-dataset) | `7d70432dfcf47a821612cbf9d34e9d9e3ad20e75` | 81 проверенный пример из `core/train`, только `source=original`; переводы на русский |
| [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections) | `4f61ecb038e9c3fb77e21034b22511b523772cdd` | 35 легитимных запросов из train и их русские переводы |

В карточках этих источников заявлена Apache-2.0; текст лицензии находится в
`LICENSE`. Правообладатели исходных данных — соответствующие авторы источников.
Это модифицированная выборка, а не исходный релиз и не официальная разметка
организаторов. Ссылки на авторов, версии и исходные метки сохранены в каждой
строке `provenance`.

Neuralchemy содержит компиляции с разными upstream-лицензиями, поэтому для
адаптации выбраны только авторские `original`. В русском наборе выбран только
поднабор, помеченный автором `openai_synthetic`; этот тег не проверяет и не
подтверждает происхождение генерации от OpenAI. Исходные компиляции в `raw/`
не подключаются к обучению и исключены из Git. Их карточки сохранены рядом.

## Какие изменения внесены

- 116 английских примеров переведены Codex на русский с сохранением намерения.
  Оригинал и перевод связывает `provenance.family_id`. Два закодированных
  payload оставлены в исходном виде, переведена окружающая инструкция.
- В русском наборе встречаются переставленные `prompt_en` и `prompt_ru`.
  Для выбранных строк русская колонка определяется по содержимому. Один
  служебный префикс переводчика удалён; исправление явно задано в скрипте.
- Категории приведены к таксономии «Астра». Исходная категория сохранена.
  Например, безобидные начальные реплики `crescendo` здесь размечены `allow`,
  поскольку сами по себе не содержат атаки, а предыдущего диалога у них нет.
  Неполные, сомнительные и явно испорченные примеры не включены в выборку.
- Косвенные инъекции помещены в `context.attachments`, перед ними стоит
  обычный запрос на пересказ. Одна только тема вложения не даёт ему прав.
- Из темы deployment в авторском примере Neuralchemy дополнительно созданы
  **144 синтетических DevOps-контрпримера**: 4 инструмента × 2 окружения ×
  3 формулировки × 3 роли × 2 языка. Это адаптация, а не буквальный перевод.
  Их ответы выведены из YAML-политики, поэтому они не являются независимым
  доказательством правильности policy-модуля.
- Исходная метка `benign` не переносится автоматически на инфраструктурные
  операции: для них проверяются роль, окружение и необходимость подтверждения.

Разметка и переводы подготовлены Codex, а не независимыми аннотаторами.
Датасет небольшой и отобран вручную: не следует считать все скачанные
22 тысячи русских строк корректными обучающими примерами нашего кейса.

## Подключение к обучению

В корневом `config.yaml`:

```yaml
data:
  extra_sources:
    - additional_datasets/adapted.jsonl
  extra_sample_weight: 0.5
  extra_similarity_threshold: 0.8
```

`train.py` сначала восстанавливает прежнее разбиение **303/102/95**.
Добавочные примеры присоединяются только к train. По нормализованному тексту
проверяются совпадения с исходными частями и близость символьного TF-IDF.
Если одна языковая версия пересекается с публичными данными, исключается
всё её семейство. Разные роли сохраняются при дедупликации внутри добавки.
Это эвристическая защита, а не гарантия обнаружения всех переводов/парафраз.

Итог: исключено 36 строк, принято **380** — **210 ru / 170 en**.
Из них 272 примера/перевода внешних источников и 108 DevOps-адаптаций.
Обучение: **683 примера**, validation: **102**, test: **95**.
Метки отложенных частей при проверке пересечений не используются.

Вес дополнительного примера равен 0.5, организаторского — 1.0.
`provenance`, метки и служебные поля не входят в признаки модели.
Отключить добавку можно через `extra_sources: []`.
Отчёт приёма и исключений сохраняется в
`reports/validation/additional_data_audit.json`; SHA-256 источников — также
в метаданных весов и `training_metadata.json`.

## Команды из корня проекта

Для обычного обучения достаточно уже подготовленного `adapted.jsonl`:

```powershell
.\.venv\Scripts\python.exe train.py
```

Для повторной подготовки из сохранённых оригиналов:

```powershell
.\.venv\Scripts\python.exe -m pip install -r additional_datasets/requirements.txt
.\.venv\Scripts\python.exe additional_datasets/prepare.py
```

Для восстановления оригиналов с закреплённых версий:

```powershell
.\.venv\Scripts\python.exe additional_datasets/prepare.py --download
```

Скачивание требует сети, повторная адаптация и обучение — нет.
Парсеры не исполняют код из датасетов. Контрольные суммы проверяются перед
подготовкой и при повторном использовании скачанных файлов.

## Текущее состояние

Подготовленные данные сохранены. В рабочем конфиге extra_sources: [],
поэтому обычное обучение пока использует только исходные 303 примера.
Для подключения включите additional_datasets/adapted.jsonl в extra_sources.
Текущая модель использует hybrid + binary_risk с порогом 0.40:
0.9316 / 94.44% на известном локальном test. Предыдущие версии целиком
сохранены в checkpoints/baseline_09175 и checkpoints/baseline_08881.
Полный снимок текущего гибрида — в checkpoints/baseline_09316.
Команды находятся в корневом README; исследование — в research/README.md.

Дополнительно сохранены авторские наборы Codex:

- `contrastive_v1.jsonl`: 48 обучающих примеров в 12 двуязычных семействах,
  обсуждение темы сопоставлено с опасным намерением; сейчас не включены в train.
- `control_v1.jsonl`: 48 диагностических сценариев, запрещённых для обучения
  меткой evaluation_only. SHA-256 и описание — в `control_v1_manifest.json`.
- `multilingual_control_v2.jsonl`: 32 параллельных диагностических сценария
  на русском, английском, испанском и немецком; только evaluation_only.
  SHA-256 — в `multilingual_control_v2_manifest.json`; результаты и ограничения
  описаны в `research/README.md`. В активный train он не входит.

Это не независимая экспертная разметка; контрольный набор после сравнений
также нельзя считать слепым финальным тестом.
